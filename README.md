# Personal Portfolio Website

This repository contains the source code for my personal developer portfolio website. Built using Next.js, TypeScript, and React, the site showcases my projects, skills, experience, and contact information.

Live Site: [nimra-portfolio-beta.vercel.app](https://nimra-portfolio-beta.vercel.app)

---

## Features

* **Interactive Projects Showcase:** Highlighted list of machine learning, web, and software engineering projects with repository and demo links.
* **Skills Component:** Categorized breakdown of programming languages, frameworks, and tools.
* **Responsive Design:** Optimized layout for mobile, tablet, and desktop viewports.
* **Performance Optimized:** Fast page loads and fluid navigation powered by Next.js and Vercel.

---

## Tech Stack

* **Framework:** Next.js / React
* **Language:** TypeScript, JavaScript
* **Styling:** Tailwind CSS / CSS Modules
* **Deployment:** Vercel
